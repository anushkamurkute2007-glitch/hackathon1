Readme for beginners. What is Edunexa

Edunexa treats attendance like a budget. Instead of showing only past percentage, it shows how many classes you can still miss (bunk budget) or how many you must attend to recover. Tagline: Know your bunk budget before the exam cell does.

Problem solved: shortages are often discovered just before exams, with no advance warning to students, mentors and parents. Edunexa gives early warnings in week 8 of a 16 week semester.

Users: students (self check and what if simulator), mentors (counselling queue), HODs (department view and approvals), exam cell (final sanction and hall ticket control).

Tech: one file called index.html with plain HTML, CSS in a style tag and vanilla JavaScript in a script tag. No build step, no backend, no local storage. All data stays in memory in JavaScript arrays.

Sample data: 12 students across 4 departments (CSE, IT, ECE, MECH), each with a mentor, 4 subjects (ML, OS, DSA, Maths), 4 classes per subject per week, 16 weeks total, 8 weeks completed. Includes 3 safe students, 3 students below 75% and 6 students above 75% but trending down.

How to open the project (double click)

  1. Save the file as index.html on your computer.
  2. Double click index.html. It opens in Chrome, Edge or Firefox.
  3. No internet needed. No install needed. If tables do not load, try another browser.
  4. To edit, right click the file, open with Notepad or VS Code, then save and refresh the browser.

How to host free on Netlify Drop

  1. Go to app.netlify.com/drop and sign in (free).
  2. Put index.html inside a folder named edunexa.
  3. Drag that folder onto the Netlify Drop page.
  4. Wait 10 seconds. You get a live link like edunexa-123.netlify.app. Share it.
  5. To update, drag the folder again.

How to host free on GitHub Pages

  1. Create a free GitHub account and a new repository named edunexa.
  2. Upload index.html to the repository.
  3. Go to settings, then pages, then deploy from branch, select main and folder root, then save.
  4. After 1 minute your site is live at yourname.github.io/edunexa.

How projection calculations work

Standard portals show the past. Edunexa projects the full 16 week semester so students know the future.

Variables:
A = attended so far. C = conducted so far. R = remaining classes. N = total semester = 256. T = target = 0.75 (75%).

Core formulae:
Current % = (A / C) x 100
Bunk budget (B) = (A + R) - 0.75 x N. Rounded down.
Recovery (K) = (0.75 x C - A) / 0.25. Rounded up. Only if below 75%.
Max possible % = ((A + R) / N) x 100
Shortage week = first future week (9 to 16) where projected % falls below 75% if current pace continues.

Case 1 (B is 0 or more): student can miss up to B remaining classes and still finish at or above 75%.

Case 2 (B is below 0): no bunks allowed. Must attend K consecutive classes to return to 75%.

Shortage week example: if a student at 76% keeps attending 76% of future classes, the projection simulates week 9, 10 and so on. The first week where the overall % drops below 75% is the shortage week. If it never drops, we show no shortage if pace continues.

Line by line: calculateBunkBudget(student) in simple language

This is the main function. A first year student can present it like this:

function calculateBunkBudget(student) {
  // 1. add attended (A)
  // 2. add conducted (C)
  // 3. current % = (A / C) x 100
  // 4. total N = 16 x 4 x 4 = 256
  // 5. remaining R = N - C (128 now)
  // 6. required = ceil(0.75 x 256) = 192
  // 7. max possible = A + R
  // 8. bunk budget = max possible - required
  // 9. recovery K if below 75%
  // 10. max achievable %
  // 11. status: safe, warning, critical, detention
  // 12. shortage week by simulation
  // 13. urgency score for sorting
}
  1. Add attended: loop through 4 subjects and total the attended hours. Example 29+30+30+29 = 118. This is A.
  2. Add conducted: same loop for conducted. In week 8 it is 32+32+32+32 = 128. This is C.
  3. Current %: divide A by C and multiply by 100. 118/128 = 92.2%. This is the past.
  4. Total N: fixed rule. 16 weeks x 4 subjects x 4 classes = 256. Full semester size.
  5. Remaining R: N minus C. 256-128 = 128 classes left in weeks 9 to 16.
  6. Required: 75% of 256 = 192. You must attend at least 192 by week 16. We round up.
  7. Max possible: if you attend 100% from now, you get A+R. Example 118+128 = 246.
  8. Bunk budget: max possible minus required. 246-192 = 54. You can miss 54 and still pass. If negative, you are in deficit.
  9. Recovery: if below 75%, formula (0.75xC - A)/0.25 tells how many straight classes will pull you back to 75%. We round up.
  10. Max achievable %: (A+R)/N x 100. Best final % if perfect from now.
  11. Status: below 65% is detention risk. Below 75% is critical. Above 75% but below 80% or budget 4 or less is warning. Else safe.
  12. Shortage week: assume you continue at same % (e.g. 76%). Simulate each future week. Find first week where overall % drops below 75%. That is your deadline.
  13. Urgency score: (75 - current %) x 10 + (20 - budget). Higher means more urgent. Table sorts by this so critical students appear first.

CSV format and import export

Use Import and Export buttons in the top bar. Export downloads EduNexa_Report_Week8_date.csv with Id, Name, RollNo, Dept, Mentor, ML_Attended, OS_Attended, DSA_Attended, Maths_Attended plus calculated totals. Import reads the same 9 first columns. Use Sample CSV button to get a template. All parsing happens in memory. No file is uploaded anywhere.

Users and tabs guide

1. Students tab: table sorted by urgency. Filters by department, status and search. Detail panel shows bunk math, what if simulator, subject bars, weekly trend, shortage week and mentor contacts.

2. Alerts tab: queue of warning and critical students. Preview formal notice, copy it, simulate mentor dispatch for one or all. Audit trail logs every dispatch.

3. Condonation tab: form for 65% to 74.9% with reason, proof reference and statement. Pipeline is mentor (auto approved on filing) to HOD to exam cell. HOD must approve before exam cell can sanction.

4. Department report tab: summary cards and table per department plus risk distribution and attendance comparison charts. Print button prints the summary.
